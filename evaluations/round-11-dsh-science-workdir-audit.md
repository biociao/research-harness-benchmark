## 2. 评审者的独立验证（clean-room，E4 级）

以下由评审者本人在独立环境完成，**不依赖任何被评项目的产物**：

1. **C01 锚点**：用 benchmark 自带 `benchmarks/humangenomics/data/panel.txt` 重算 → **2,504 个体 / 26 人群 / 5 超级人群**（逐人群 96/61/86/…/108），与全部 5 个项目的报告值一致。
2. **C02 单例口径裁决**：对 chr21 v5b VCF（209,774,472 B，取 kimi 项目内的下载副本，md5 `937410d1…` 与五家记录一致）做全量流式重算：

| 口径 | 独立实测 | 谁报了这个值 |
|---|---:|---|
| 总记录 | **1,105,538** | 全部 5 项目 + 锚点 ✓ 精确 |
| 双等位 SNP | **1,054,447** | 全部 5 项目 + 锚点 ✓ 精确 |
| 双等位 SNP 且 AC=1 | **452,351** | deepseek、glm-5.3 |
| 双等位记录（SNP+indel）AC=1 | **452,694** | **= 基准锚点**；deepseek 中间件 `chr21_biallelic_singletons.txt` 内亦存此值 |
| ΣAC=1 位点 | **452,695** | glm-5.3-flash（与锚点差恰 1，±1 容差内） |
| 任一 ALT AC=1 位点 / AC=1 等位数 | **452,773 / 452,778** | kimi、glm-5.3 |

   **裁决：五个项目在此指标上零伪造、零计算错误；全部分歧源于 singleton 的四种定义口径。锚点 452,694 = 双等位记录 AC=1 口径。**
3. **锚点"51,091 indels"的算术解剖**：1,105,538 − 1,054,447 = 51,091，即**锚点的"indel"实为"非双等位 SNP 残差"**（含双等位 indel 43,988 + 多等位 indel 位点 1,490 + 混合 965 + **多等位 SNP 位点 3,892** + SV 756，加和恰为 51,091，deepseek 的分解文件可逐项对上）。→ **基准锚点自身标签错误**（详见 §6）。

### 9.3 Part B 结构性发现

1. **循环论证谱系 = Tyson 基准的核心区分度**：同一陷阱四种处理——glm-5.3 完全中招（标签当 bins、GMM 未用、报告虚假表述）；glm-5.2 半循环（参考锚定 + SS_OVERRIDE 硬编码削弱 16S 链）；kimi 参考引导但**事前披露**且无参考结构独立成立；flash 完全独立（GC×depth + 双向对照）。v2 应把"独立分箱证据链"列为显式评分项。
2. **管线忠实度分化**：glm-5.3 是唯一出现"提交脚本≠实际运行"（bwa aln 0.2% vs bwa mem 80.3%）且 provenance 与代码矛盾的；kimi 提交脚本含僵尸引用（指向不存在的 canu 产物）；glm-5.2 五项子分析无脚本存档；flash 脚本-产物一致但全部硬编码死路径。
3. **环境可复现全线溃败**：四家无一可在交付位置重跑（chdir 死路径 / ROOT 硬编码+无 lock / RPATH 烘焙崩溃 / WS 硬编码+无 pin）。D3 的最大共性扣分项，也是报告审稿完全看不见的部分。
4. **旧假设被推翻**：benchmark 与 R01 时代认定"原始 Sanger reads 不可获得"→ 四家全部实测取得 180,713 条 reads（glm-5.3 与 flash 逐字节核验）。C04 的 data_availability 判定应更新（见 §9.5）。
5. **诚实的定价**：kimi 全程披露（参考引导/正文未获/SNP 未做）仍得 69；flash 诚实披露近似但在弱证据上标"✅复现"被扣到 D2 6.5；glm-5.2 "✓"式定性对照掩盖数值差（16S/nif 两处夸大）直接压 D2/D4。
6. **报告口径双向失真在 Tyson 上同样成立**：R03 给 glm-5.2/5.3 的 9.4/9.3 vs R11 73/58（−21/−35）；R04 给 flash 43.25 vs R11 69（+25.75）。报告审稿既高估了"读起来完整"的，也低估了"报告朴素但工程真实"的。
