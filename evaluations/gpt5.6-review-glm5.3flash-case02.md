## D1–D5 逐维详评

### D1 文献检索与获取

- 报告给出原论文的 PMCID `PMC4750478`、Nature 补充 PDF、官方 1000 Genomes VCF/panel，以及输入文件 SHA-256，paper → dataset → artifact 链较完整。
- 正确指出 Supplementary Table 1 实为“人群名称与样本量表”，并明确报告“论文未发布逐染色体计数表”。这是重要且透明的引用勘误。
- 使用官方 EBI 数据，检查 `Content-Length`、`bgzip -t` 和样本 panel 双向差集，避免了将二手数据当原始输入。
- 对 v5a→v5b“常染色体内容不变”的结论仅援引未随材料提供的 IGSR 发布说明，且承认“未逐位点比对”，证据有限。
- 已定位 Supplementary Table 5，但没有转录或核验其中数值；因此未建立 C05 所要求的 paper value → computed value 直接证据链。
- C02 发现参考表不存在是合理的文献核查结果，但不能把另行设计的比例范围当作原 exact-count claim 的原始参考证据。

### D2 内容理解与逻辑推理

- 对 C01–C05 拆成 C1–C9 的主题映射总体可辨认：C1→C01，C2–C4→C02，C5–C7→C03，C8→C04，C9→C05。
- 报告能区分 chr21 与全常染色体、定性论文论断与 ARI 操作化、混合人群 AMR 与其他大陆组；PCA 未达阈值也被如实报告为 `PARTIAL`。
- C02 的拆解不忠实：原要求是 SNP/indel/singleton 逐染色体计数 `±1`，C2–C4 改成 1.2%–1.8%比例和“稀有变异>20%”。这只能构成替代分析，不能支持原 claim。
- C03 的比例换算依赖“变异密度均一”假设，但观测已出现 SNP 1.13–1.18×、indel 1.21–1.25×系统偏移。去除全局偏移后再判定“形状一致”证明的是群体间相对模式，而非原始幅度被准确换算验证。
- C3 的叙述称 indel 份额“应略低于 SNP”，实际结果为 1.376% 高于 SNP 的1.300%；判据却只检查宽区间 `[0.8%,2.0%]`，没有检验其文字预测，存在内部逻辑不一致。
- C9 明示使用“事后修订判据”，且原预注册范围偏低约三倍。透明披露值得肯定，但以修订后的宽区间给 `PASS` 存在明显的事后合理化风险。
- “AMR 是未达阈值的唯一机制”措辞过强；当前混淆矩阵可以表明主要误差集中于 AMR，但不能排除位点选择、缺失处理、算法或群体内部结构的其他贡献。

### D3 代码生成与复现规范

- 随附完整 shell、R、Python 代码及关键结果；编排侧确认 97 个文件哈希一致，支持“代码确实执行”的 E2 级判断。
- 样本双向 diff、ARI 与 `mclust::adjustedRandIndex` 的 `stopifnot`、Fst 与 vcftools 逐位点对账，均是有效 automated checks。
- Fst 交叉验证达到 `r≈1`、最大偏差约 `5×10^-7`，强力支持本地 W&C 实现与 vcftools 输出的一致性；但这只验证实现，不能验证与论文发布值相等。
- `run_all.sh` 没有调用 `04b_pca_tune.sh`，而 `06_claims_table.R` 会在敏感性文件已存在时读取它。因此所谓“一键复现”不能从干净目录生成报告宣称的完整敏感性结果。
- `config.sh`、多个 R 脚本使用机器特定绝对路径 `/Volumes/repo/...`，第三方无法按附录命令直接在任意目录运行。
- 环境存在不一致：锁文件是 vcftools 0.1.16，报告及注释称 0.1.17；R 使用系统库且没有精确包版本；Python 脚本调用 `python3` 而非锁定环境的解释器，锁文件也未显示 numpy 依赖。
- 没有提供 clean-room 从空缓存、空结果目录重跑的证据，因此尚不能评为 E3。

### D4 实验设计与结果可视化

- C01 设计直接、清晰：VCF与panel双向核验，并对26个人群逐项比较，是与科学问题匹配的实验。
- PCA 使用 MAF过滤、LD剪枝、多个PC数、三种聚类方法和三套剪枝参数，且报告混淆矩阵，设计较完整。
- PCA 的主要指标明确为 ARI≥0.9，实际最高0.8845；结果没有被包装为达标，是良好做法。
- Fst 同时报告全SNP、MAF≥5%和LD剪枝位点集，并提供均值、中位数、SD及负值位点数，较好呈现估计不确定性和口径敏感性。
- C02 没有可用的逐染色体论文 baseline，所用1.2%–1.8%区间缺少在材料内可独立核查的推导或预注册依据，不能替代 `±1` 比较。
- C05 没有论文发布数值的逐对比较，热图和格局排序只回答“结果是否看起来合理”，没有回答“是否与论文值一致”。
- PNG存在且尺寸、文件哈希可核查，但本评审文本通道不可见，无法审查标签、图例、遮挡或视觉论证质量。

## D1–D5 逐维详评

### D1 文献检索与获取

- 文献链较完整：报告给出 Auton et al. 正文的 PMCID `PMC4750478`、Nature 补充 PDF、官方 EBI VCF 和官方 sample panel，具备 paper → supplementary material → dataset → local artifact 的基本链条。
- 数据 provenance 较好：记录 VCF/panel 的 URL、字节数及 SHA-256；编排侧还报告“97 文件 SHA-256 全部一致，0 缺失 0 不一致”。
- 对 Supp Table 1 的纠错披露明确且合理：报告指出其内容是 population descriptions/sample counts，而不是逐染色体 variant counts。这一发现提升了检索可信度。
- 然而，发现题目引用有误并不等于完成 C02。答卷没有找到另一个权威的 chr21 SNP/indel/singleton exact-count reference，只能证明“论文材料不足以执行指定 ±1 比对”。
- Supp Table 5 已定位到 PDF 第117页并保存截图，却没有 OCR、人工转录或双人核对，因此 paper → Fst numeric evidence 链在最关键一环中断。
- v5a 与 v5b 常染色体一致仅依据发布说明，未提供该说明原文证据，也未逐位点验证。

### D2 内容理解与逻辑推理

- 对 C01 的理解准确：同时检查样本数、26个人群、5个超级人群、VCF/panel 双向差集以及各人群样本数。
- 对 singleton 的 AC=1 定义作了有价值的澄清，指出每个 AC=1 位点对应一个非参考拷贝，均值关系应为 `N_singleton/2504`，不是 `2N/2504`。
- PCA 部分能够如实报告主结果 ARI=0.8742、网格最优=0.8845，且没有将其伪装成达到 0.9；将答卷 C8 判为 PARTIAL 比判 PASS 更诚实。
- 但 C2–C4 并非 C02 的忠实拆解：原 claim 要求逐染色体 SNP/indel/singleton 与 reference exact match ±1，答卷改成常染色体占比区间和“稀有变异富集 >20%”。这些是替代性 plausibility checks，不是原 claim 的三个组成部分。
- C5–C7 对 C03 的处理混合了可验证关系和自定义容差。观察值相对换算期望偏离约 13%–25%，随后通过“去全局偏移后的形状一致性”判 PASS，实质上弱化了 proportional consistency 的幅度要求。
- “AMR 是未达阈值的唯一机制”表述过强。混淆矩阵能显示主要误差来源，不能排除 SNP 选择、LD 参数、距离度量、单染色体采样噪声及 k-means 模型错配等其他机制。
- C9 明确使用“事后修订判据”，且原预注册范围与结果差约数倍。透明披露值得肯定，但据此将 benchmark C05 判为 PASS 不成立。
