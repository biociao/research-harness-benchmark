# 五维科研能力 Rubric

## D1 文献检索与获取（15%）

评价：
- 是否找到原始论文/权威版本
- 是否识别开放性、版本和数据来源问题
- 是否能建立 paper → dataset → accession → evidence 链
- 是否避免把二手信息当作原始证据

## D2 内容理解与逻辑推理（30%）

评价：
- 是否准确理解研究问题与假设
- 是否能逐条拆解 scientific claims
- 是否能区分结果、解释、推断
- 是否能识别冲突证据、边界条件和不可复现部分
- 是否避免过度推断

## D3 代码生成与复现规范（25%）

评价：
- 代码是否真正执行
- 参数是否完整
- 依赖/环境是否可恢复
- 中间结果是否可追踪
- 是否存在 automated checks
- 第三方是否能够重新运行
- 是否达到 Bronze / Silver / Gold 等可复现等级

## D4 实验设计与结果可视化（20%）

评价：
- 实验设计是否回答明确科学问题
- 是否有适当的 baseline / control / validation
- 是否进行关键指标的定量比较
- 图表是否服务科学论证
- 是否报告误差、异常与不确定性

## D5 研究过程与效率（10%）

评价：
- 任务完成率
- agent iteration
- runtime
- token/compute cost
- 人工介入程度
- 失败恢复能力
- 是否形成端到端闭环

> 若缺少 runtime / cost / interaction log，不得凭报告质量推断效率；应标记为 evidence-limited。

## 审稿式证据等级

### E0 — 无证据
只给结论，无可核查材料。

### E1 — 报告证据
报告中有描述/截图，但无法独立检查。

### E2 — 可核查工件
有代码、日志、结果文件或数据 provenance。

### E3 — 可独立运行
第三方可在指定环境重新执行关键步骤。

### E4 — Clean-room verified
独立评测者在未参与原实验的环境中完成复现。

建议高分：
- 8+：关键结论至少 E2
- 9+：关键结论至少 E3
- 9.5+：核心结论建议 E4

## 科研诚信修正

以下行为应扣分：
- 把未执行代码描述为已执行
- 把推测写成实验结果
- 隐瞒与原论文的关键差异
- 无来源地补全缺失数据
- 使用无法追溯的数据/结果
